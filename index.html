60-second explain

What this is

You built a folder-based AI specialist using ICM (Interpretable Context Methodology — the folder-as-architecture pattern: identity.md, rules.md, examples.md, reference/, README.md).

It might work. You're not sure. There's no way to grade it cold.

This vetter grades it. Drop your specialist folder in. The vetter reads it (read-only — never modifies your files), decomposes the folder into atomic claims, tests each claim against the folder's own evidence, and returns a structured Report with a CONFIDENCE grade.

Then you ship a folder you can stand behind. Or you fix the gaps the Report named.

CONFIDENCE grade tells you whether you can ship the folder cold. Below VERIFIED → don't ship. At VERIFIED+ → ship.

Lineage

Built ICM-pure

Built atop Jake Van Clief's Interpretable Context Methodology as taught at the Quantum Quill Lyceum. The 60/30/10 method runs the grader (60% deterministic file checks, 30% rule-based logic, 10% genuine judgment). The multiple-smaller-voice-files pattern runs the voice register. Austin Kleon's "Show your work" runs the public red-face test discipline — the Vetter graded its own canon AND itself before public ship.

Born from watching atomicity converge across five independent builders in eight days: Jake's ICM + Disler's verifier-agent + DeRonin's content-engine + the Crèche moral physics + this Vetter. We decided the next move was to make that gradeable.
